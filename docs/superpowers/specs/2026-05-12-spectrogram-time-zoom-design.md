# Spectrogram Time Zoom Design

日期：2026-05-12

## 1. 背景

当前 ZiQi 已经可以在主工作区显示整首静态 spectrogram：上方是 waveform overview，左侧是 A0-C8 钢琴音高轴，中间是黑底能量频谱，播放游标和固定时间网格贯穿视图。

这个整首压缩视图适合确认音频整体结构，但不适合扒谱时观察局部音符、泛音和瞬态细节。下一步需要先补齐横向时间 zoom，让用户可以放大某个时间位置的频谱，并通过明确的导航条在整首音频中左右移动观察窗口。

## 2. 目标

- 默认打开或导入音频后，频谱主视图显示一个适合观察的时间窗口。
- 对于超过 10 秒的音频，默认显示前 10 秒。
- 对于不超过 10 秒的音频，默认显示完整音频。
- 用户可以通过 `Ctrl + 垂直滚轮` 横向放大或缩小频谱。
- 缩放以鼠标所在的频谱时间点为中心。
- 用户可以通过真实横向滚轮左右平移观察窗口。
- 用户可以通过全曲导航条拖动或点击来移动观察窗口。
- 播放不会自动滚动当前观察窗口。
- 频率轴保持 A0-C8 完整显示，不做纵向 zoom。
- zoom/pan 状态只属于运行时 UI，不保存到 `.ziqi` 项目文件。

## 3. 非目标

第一版不做以下内容：

- 纵向频率或音高 zoom。
- 频率范围裁剪或可配置频率范围。
- 自动跟随播放滚动。
- `Shift + 垂直滚轮` 横向平移。
- mini waveform 导航条。
- 选择区间、循环当前窗口或标注区间。
- hover 显示精确时间、音名或频率。
- 将 zoom/pan 状态写入项目文件。
- 重新生成更高时间分辨率的 spectrogram 数据。

## 4. 推荐方案

采用“主频谱视图 + 全曲导航条”的交互模型。

主频谱视图只显示当前时间 viewport 内的 spectrogram 和 waveform strip。全曲导航条显示整首音频时间范围，并用一个窗口滑块表示当前 viewport。用户在主频谱上用滚轮做精细缩放和移动，在导航条上做粗定位和拖动。

选择该方案的原因：

- 主频谱只负责观察局部细节，导航条只负责整首定位，语义清楚。
- 用户 zoom 后仍能知道当前窗口在整首音频中的位置。
- 滑块提供稳定的鼠标拖动入口，适合不熟悉滚轮手势的用户。
- 后续可以自然扩展自动跟随播放、循环当前窗口、区间选择等能力。

未采用的方案：

- 只在主频谱上滚轮 zoom/pan，不加导航条。实现更少，但用户 zoom 后容易迷失当前位置。
- 让上方 waveform overview 兼任全曲导航条。空间更省，但 waveform strip、播放游标、viewport 框和拖动交互会挤在同一层，语义过重。

## 5. 状态模型

第一版只引入横向时间 viewport：

```ts
interface SpectrogramViewport {
  startMs: number;
  durationMs: number;
}
```

派生值：

```ts
const endMs = startMs + durationMs;
```

初始化规则：

- 音频时长 `<= 10_000ms`：`startMs = 0`，`durationMs = audioDurationMs`。
- 音频时长 `> 10_000ms`：`startMs = 0`，`durationMs = 10_000`。
- 如果音频时长无效或为 0，视图退化为不可交互状态。

约束规则：

- `durationMs` 最小为 `1_000ms`。
- `durationMs` 最大为整首音频时长。
- `startMs` 始终限制在 `0..audioDurationMs - durationMs`。
- 当用户导入或打开另一首音频时，viewport 重置为默认值。
- 当前播放时间不驱动 viewport。

状态位置：

第一版优先把 viewport 状态放在 `SpectrogramView` 或其直接父组件附近，因为它只是频谱视图交互状态，不需要保存，也不参与音频分析服务。后续如果其它面板需要同步当前观察窗口，再上提到 `App`。

## 6. 主频谱交互

### 6.1 缩放

`Ctrl + 垂直滚轮` 横向缩放 viewport。

规则：

- 鼠标在频谱区域内时，以鼠标所在时间点为缩放中心。
- 放大时 `durationMs` 变短，最短为 `1_000ms`。
- 缩小时 `durationMs` 变长，最长为整首音频时长。
- 缩放后尽量保持鼠标指向的音频时间位于同一屏幕 x 位置。
- 如果缩放结果超出音频边界，调整 `startMs` 使 viewport 留在有效范围内。

### 6.2 平移

真实横向滚轮横向平移 viewport。

规则：

- `deltaX > 0` 向后移动时间窗口。
- `deltaX < 0` 向前移动时间窗口。
- 平移步长按当前 viewport 宽度的比例计算，例如每次移动窗口宽度的 5%-10%。
- 平移后 clamp 到音频边界。

普通垂直滚轮不被频谱接管，保留页面默认行为。

### 6.3 播放游标

- 如果 `currentTimeMs` 位于 viewport 内，主频谱和上方 waveform strip 显示播放游标。
- 如果 `currentTimeMs` 不在 viewport 内，主频谱和 waveform strip 不显示播放游标。
- 全曲导航条始终显示播放游标，只要音频时长有效。
- 播放不会自动滚动 viewport。

## 7. 渲染规则

`SpectrogramOverview.frames` 继续保存整首音频的分析数据。渲染层根据 viewport 选择和聚合当前窗口内的 frames。

主频谱：

- 横轴映射 `viewport.startMs..viewport.endMs`。
- 纵轴继续使用 A0-C8 对数频率映射。
- 画布宽度不改变，改变的是时间到 x 坐标的映射。
- 当前时间网格基于 viewport 重新计算。

上方 waveform strip：

- 与主频谱使用同一个 viewport。
- 只显示当前窗口内的 waveform 概览。
- 不再承担整首 overview 的定位语义。

全曲定位交给导航条。

## 8. 全曲导航条

在频谱主视图下方增加全曲导航条。

结构：

```text
0:00 ----------------[ current viewport ]---------------- 3:42
                         |
                     playhead
```

规则：

- 轨道表示 `0..audioDurationMs`。
- 窗口滑块表示 `viewport.startMs..viewport.endMs`。
- 拖动窗口滑块会平移 viewport，不改变 zoom。
- 点击轨道空白处会把 viewport 中心移动到点击时间附近。
- 播放游标始终显示在导航条上。
- viewport 等于整首音频时，滑块铺满轨道。
- viewport 为 1 秒时，滑块可以有最小视觉宽度，保证可拖动；实际时间范围仍是 1 秒。

显示信息：

- 轨道左右端显示整首起止时间。
- 导航条显示当前窗口范围，例如 `0:37-0:47`。
- 如果滑块内部空间不足，窗口范围可以显示在滑块外侧或 hover/title 中。

第一版不在导航条中绘制 mini waveform，保持定位控件简洁。

## 9. 边界与错误处理

- 没有项目或没有有效音频时，不显示可交互 zoom 控件。
- spectrogram 生成中时，维持当前生成中状态；viewport 可以初始化，但不需要复杂进度。
- 音频时长异常时，控件退化为不可交互状态，不抛出 UI 错误。
- 导入或打开新音频后，viewport 重置，不继承上一首音频的 zoom/pan。
- zoom/pan 状态不写入 `.ziqi`。

## 10. 测试策略

组件测试：

- 长音频默认 viewport 为前 10 秒。
- 短音频默认 viewport 为完整时长。
- `Ctrl + wheel` 会改变 viewport duration。
- `Ctrl + wheel` 以鼠标 x 位置对应的时间点为锚点。
- 横向滚轮会移动 viewport，并被音频边界限制。
- 主频谱、waveform strip 和时间网格都基于 viewport 显示。
- 播放游标在 viewport 内时显示在主视图中。
- 播放游标在 viewport 外时主视图隐藏游标。
- 导航条始终显示播放游标。
- 拖动导航条滑块会平移 viewport。
- 点击导航条轨道会把 viewport 移动到点击时间附近。

项目文件测试：

- 保存 `.ziqi` 时不包含 viewport 或 zoom/pan 状态。

验证命令：

```text
npm test
npm run build
```

Electron smoke：

- 导入一首超过 10 秒的真实音频。
- 频谱默认显示前 10 秒。
- `Ctrl + 滚轮` 能以鼠标位置为中心缩放。
- 横向滚轮或导航条能左右移动观察窗口。
- 播放不会自动滚动当前观察窗口。
- 播放游标在主视图窗口内可见，窗口外仅在导航条可见。
- 保存并重新打开项目后，zoom/pan 不被持久化，viewport 回到默认值。

## 11. 验收标准

- 导入或打开超过 10 秒的音频后，频谱主视图默认显示前 10 秒。
- 用户可以通过 `Ctrl + 垂直滚轮` 横向缩放，范围为整首音频到 1 秒。
- 缩放以鼠标所在时间点为中心。
- 用户可以通过真实横向滚轮左右移动观察窗口。
- 用户可以通过全曲导航条拖动或点击移动观察窗口。
- 播放不会自动滚动观察窗口。
- 全曲导航条清楚显示当前 viewport 在整首音频中的位置。
- 频率轴仍完整显示 A0-C8。
- `.ziqi` 文件不保存 viewport 状态。

## 12. 结论

第一版 spectrogram zoom 应聚焦横向时间观察能力：默认 10 秒窗口、鼠标锚定缩放、横向滚轮平移、全曲导航条定位。该设计保留现有 spectrogram 数据边界和频率轴，避免把二维 zoom、自动跟随播放和项目持久化混入第一版，实现范围清楚，后续迭代空间充足。
